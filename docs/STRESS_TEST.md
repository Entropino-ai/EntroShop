# Synthetic Stress Test

Deliberately harsh data synthesized to probe EntroShop beyond the 200 public
sessions.

## Part A — synthetic simulator sessions (mini private set)

300 sessions generated by sampling catalog products as hidden targets —
**40% deliberately drawn from the 5,000 most "generic-feature" products**
(top-4 disclosed constraints with the largest posting overlap, e.g.
`Imported`/`Machine Wash` boilerplate), 60% uniform random — then replayed
through the official evaluator's simulator.

| Metric | Public set (200) | Synthetic (300, harsh) |
|---|---|---|
| Hit@10 | 1.000 | 0.933 |
| MRR | 0.724 | 0.6474 |
| MTTC | 1.59 | 2.807 |
| TechnicalScore | 0.9055 | 0.8248 |

**Miss classification (20/300):**

- `family-ambiguous` **19** — the target shares *all* disclosed constraints
  and the exact coarse category with 218–1,069 near-identical listings
  (same seller family). No agent can do better than the disclosed
  information bound; the worst case is a coin flip (e.g. one miss had
  exactly 2 candidates with identical signals, the popularity prior chose
  the other one).
- `not-in-pool` **0** — no retrieval bugs.
- `ranked-low` **1** — a two-candidate coin flip, not a signal gap.

Interpretation: on natural sampling the system stays ≈ public-set level
(1.000); the 0.933 reflects the deliberately oversampled hard family class,
which the competition's disclosure policy itself cannot resolve.

## Part B — adversarial chat inputs (23/23 no crashes)

Empty input, single chars, number-only, contradictory colors
("black white belt"), impossible combos ("a belt that is also a waterproof
hat"), mixed language ("黑色belt 预算三十 dollars"), negation
("not black, no leather"), caps/punctuation, typos ("blck lthr blt"),
filler-only, exact repeats ×3, long rambling, size attributes, contradictory
adjectives, emoji-only, pronoun references.

All 23 produce either recommendations or guidance chips without a server
error. Documented weaknesses (known limitations, not crashes):

- **negation** ("not black") is not yet modeled — the color is added, not
  excluded
- **typos** are not corrected (pre-cleaned input is assumed)
- **size** attributes are not indexed as a facet
- **pronoun references** ("那条黑色的怎么样") are not resolved
